# Kura Toolkit テーブル定義

本アプリはデータベースを使用せず、設定と音声機能のデータを JSON ファイルで保存する。
本書では JSON ファイル 1 つを 1 つの表として、項目・型・関連を定義する。

- 入れ子のオブジェクトは `親.子` の形で表す。配列の要素は `配列[]`、キーが可変のオブジェクトは `<キー>` で表す
- 型は TypeScript の表記に合わせる (`string` / `number` / `boolean` / `null` / 配列 / 列挙値)
- 「必須」が「-」の項目は省略されることがある
- 「関連」には、値が参照する他の表・ファイル・定義を記す
- 場所の `<ライブラリ>` はライブラリディレクトリ、`<モデル>` はモデルディレクトリ、`<キャッシュ>` はキャッシュディレクトリ
  (システム仕様 3 章「保存場所」・13.2)、
  `~` はホームディレクトリ
- 書き込みは一時ファイル (`<ファイル名>.tmp`) へ書いてから置き換える (書き込み途中の終了で内容を壊さないため。
  音声機能は `main/services/voice/json-file.ts` の `writeJsonFile` を使う)。例外として model.json は、Python が作成中の
  声のモデルのフォルダ (`.staging-<ID>/`) の中に直接書く。フォルダは meta.json を書いた後に名前を変えて `<ID>/` になるため、
  書きかけの model.json が声のモデルとして使われることはない
- manifest.json・ready-model-overrides.json・voice-presets・vectorizer-presets は、ファイルが無ければ初期状態として扱う。これらと meta.json は、
  それ以外の理由で読めない・JSON として解釈できない場合に `DATA_FILE_CORRUPT: <パス>` で失敗させる (空の内容として
  扱うと、次の書き込みで元の内容が失われるため)。settings.json の扱いはシステム仕様 3 章。配布元から得た情報の
  キャッシュ (model-list.json・model-sources.json) と、キャッシュの利用記録 (cache.json) は、読めなければ取得し直す
  (cache.json は空として扱う)
- 学習用の音声は学習セットとしてモデルディレクトリに保存する (set.json。システム仕様 13.15)

## settings.json

アプリの設定。読み込み時に既定値と deep-merge して欠損した項目を補う。保存のタイミングはシステム仕様 3 章。
ファイルがあるのに読めない場合は上書きせず、起動時に続け方を確かめる (既定の設定で続ける場合は、読めなかったファイルを
同じフォルダに `settings.broken-<YYYYMMDD-HHmmss>.json` として残す。システム仕様 3 章)。
`storage.*` は先にファイルへ書き、書けた場合だけ起動中の設定に反映する (書けなければ `SETTINGS_SAVE_FAILED`)。

## manifest.json (ライブラリ)

Python 本体とパッケージ一式の取得記録。取得し終えた項目だけを記録し、途中で失敗・中断した項目は記録しない。
状態の判定 (missing / installed / outdated / broken) は、この記録と `spec.ts` の定義、実ファイルの有無を照合して行う。
ライブラリディレクトリを移動すると、中身と一緒に移る。

| 項目 | 型 | 必須 | 説明 | 関連 |
|---|---|---|---|---|
| version | `1` | ○ | 記録の形式のバージョン | |
| python | object \| null | ○ | Python 本体の記録。null = 未取得 | `spec.ts` の `PYTHON_SPEC`、`<ライブラリ>/python/` |
| python.version | string | ○ | 取得した版 (例: `3.11.17+20261003`) | `PYTHON_SPEC.version` |
| python.installedAt | number | ○ | 取得した日時 (UNIX ミリ秒) | |
| components.`<ID>` | object | - | パッケージ一式の記録。キーは `separator` / `converter` / `tts` / `tts-train` | `spec.ts` の `COMPONENT_SPECS[].id`、`<ライブラリ>/<audio-separator\|applio\|style-bert-vits2>/` |
| components.`<ID>`.version | string | ○ | 取得した版 (例: `applio-3.6.5-1`) | `COMPONENT_SPECS[].version` |
| components.`<ID>`.variant | string | - | 環境による違い (Windows・Linux は `cu126` / `cu128` / `cu130` / `cpu`、macOS は `darwin-arm64`)。現在の環境と違えば outdated | `componentVariant()` |
| components.`<ID>`.installedAt | number | ○ | 取得した日時 (UNIX ミリ秒) | |
| components.`<ID>`.broken | boolean | - | true = 動作確認に失敗し、取り直しが必要 (ライブラリの移動後など) | |

## manifest.json (モデル)

ダウンロードしたモデルの取得記録。記録の仕方は manifest.json (ライブラリ) と同じ。モデルディレクトリを移動すると、
中身と一緒に移る。利用者が学習・取り込みした声のモデルは記録しない (meta.json で管理する)。

| 項目 | 型 | 必須 | 説明 | 関連 |
|---|---|---|---|---|
| version | `1` | ○ | 記録の形式のバージョン | |
| models.`<項目ID>` | object | - | モデルの記録。キーは `model:converter:rmvpe`・`model:tts:bert-ja`・`model:tts:ready:<名前>`・`model:separator:<ファイル名>` など | `spec.ts` の `MODEL_SPECS[].id`、model-list.json の `models[].filename` |
| models.`<項目ID>`.version | string | ○ | 取得した版 (分離モデルは `1`) | `MODEL_SPECS[].version` |
| models.`<項目ID>`.installedAt | number | ○ | 取得した日時 (UNIX ミリ秒) | |
| models.`<項目ID>`.files | string[] | ○ | 取得したファイル (`<モデル>` からの相対パス、区切りは `/`。例: `audio/conversion/predictors/rmvpe.pt`)。削除時に使う。展開する zip (NLTK のデータ) は zip のパスを記録する (zip は展開後に消し、削除時は zip の名前から拡張子を除いた展開先のフォルダを消す) | |

## set.json

学習セット 1 件の情報。ディレクトリ名が `id` と一致する。音声は同じディレクトリの `audio/<audios[].id>.wav`
(16bit・モノラルの WAV) に置く。記録の無いフォルダは学習セットとして扱わず、記録に無い音声のファイルは起動時に消す。

| 項目 | 型 | 必須 | 説明 | 関連 |
|---|---|---|---|---|
| id | string | ○ | 学習セットの識別子 (UUID) | ディレクトリ名 |
| feature | `'converter' \| 'tts'` | ○ | 機能 (音声変換 / 読み上げ) | `audio/<conversion\|tts>/training-sets/` |
| name | string | ○ | 利用者が付けた名前 | |
| language | `'ja' \| 'en' \| 'zh'` | - | 読み上げの学習セットの言語 (`feature = tts` のとき必須、`converter` では持たない)。作成後は変えない | `shared/voice/languages.ts`、corpus |
| mode | `'sentences' \| 'custom'` | - | 読み上げの学習セットのモード。`sentences` = サンプル文から作成、`custom` = 任意の文で作成。無い場合は `sentences` (モードを選べるようになる前に作った学習セット)。`converter` では持たない。作成後は変えない | `TrainingSetMode` |
| groups | object[] | - | 任意の文で作成する学習セットのグループ (加えた順。`mode = custom` のときだけ持つ) | |
| groups[].id | string | ○ | グループの識別子 (UUID) | `audios[].sentenceId` |
| groups[].text | string | ○ | 本文 (その音声の書き起こし。空も可。学習では空白だけのものを使わない) | |
| createdAt | number | ○ | 作成の日時 (UNIX ミリ秒) | |
| updatedAt | number | ○ | 名前・音声を最後に変えた日時 (UNIX ミリ秒)。一覧の並び順に使う | |
| audios | object[] | ○ | 音声の一覧 (追加した順) | |
| audios[].id | string | ○ | 音声の識別子 (UUID) | `audio/<ID>.wav` |
| audios[].name | string | ○ | 表示名 (録音は録音した日時、ファイルは元のファイル名) | |
| audios[].source | `'recording' \| 'file'` | ○ | 録音か、指定したファイルを変換したものか | |
| audios[].sentenceId | string | - | 読み上げの学習セットで、この音声が読み上げた文の ID (`feature = tts` のとき必須。1 つの文に 1 つ)。任意の文で作成する学習セットではグループの ID | corpus の `sentences.id`、`groups[].id` |
| audios[].durationSec | number | ○ | 長さ (秒) | |
| audios[].sampleRate | number | ○ | サンプリング周波数 (Hz) | |
| audios[].channels | number | ○ | チャンネル数 (1) | |
| audios[].addedAt | number | ○ | 追加の日時 (UNIX ミリ秒) | |

## meta.json

声のモデル (学習・取り込み) 1 件の情報。ディレクトリ名が `id` と一致する。
作成中のモデルは `.staging-<ID>/` に作り、このファイルを書いてから `<ID>/` に名前を変える。
すぐに使えるモデルはこのファイルを持たず、ダウンロードしたファイル (`<モデル>/audio/tts/ready/<名前>/`) と
ready-model-overrides.json から同じ形の情報を組み立てる (`id` は `ready:<配布時の名前>`)。

| 項目 | 型 | 必須 | 説明 | 関連 |
|---|---|---|---|---|
| id | string | ○ | モデルの識別子 (英数字とハイフン) | ディレクトリ名 |
| feature | `'converter' \| 'tts'` | ○ | 機能 (音声変換 / 読み上げ) | `audio/<conversion\|tts>/voices/` |
| name | string | ○ | 利用者が付けた名前 | |
| origin | `'user' \| 'existing'` | ○ | 区分。ユーザーモデル (`user`: このアプリで学習して作ったモデル) か、既存モデル (`existing`: ダウンロード・取り込みしたモデル) か | |
| createdAt | number | ○ | 作成・取り込みの日時 (UNIX ミリ秒) | |
| readyItemId | string | - | すぐに使えるモデルの元になったダウンロード項目。すぐに使えるモデルの情報を組み立てるときだけ持ち、ファイルには書かない | manifest.json (モデル) の `models.<項目ID>` |
| distributedName | string | - | すぐに使えるモデルの配布時の名前 (`jvnv-F1-jp` など)。`name` が空の間の表示名に使う。すぐに使えるモデルの情報を組み立てるときだけ持ち、ファイルには書かない | |
| rvc.version | string | - | RVC のバージョン (`v1` / `v2`)。`feature = converter` のとき必須 | model.json の `version` |
| rvc.sampleRate | number | - | サンプリング周波数 (Hz) | model.json の `sr` |
| rvc.f0 | boolean | - | ピッチ情報を使うモデルか | model.json の `f0` |
| rvc.vocoder | string | - | ボコーダー (`HiFi-GAN` など) | model.json の `vocoder` |
| rvc.embedder | string | - | 埋め込み方式 (`contentvec` など)。未取得なら対応する埋め込みモデルのダウンロードを求める | model.json の `embedder_model`、`spec.ts` の `RVC_EMBEDDER_ITEMS` で対応付けたダウンロード項目 (manifest.json (モデル) の `models.<項目ID>`) |
| rvc.speakers | number | - | 話者数 | model.json の `speakers` |
| rvc.hasIndex | boolean | - | 検索用インデックス (`model.index`) があるか | 同じディレクトリの `model.index` |
| tts.modelType | `'jp-extra' \| 'multilingual'` | - | モデルの種類 (JP-Extra 版か多言語版か)。`feature = tts` のとき必須 | `config.json` の `version` (`JP-Extra` で終われば JP-Extra 版) |
| tts.languages | `('ja' \| 'en' \| 'zh')[]` | - | 使える言語 (JP-Extra は `['ja']` 固定、多言語版は利用者が選ぶ) | `shared/voice/languages.ts` |
| tts.styles | string[] | - | スタイル名 (ID 順) | `config.json` の `data.style2id` |

## voice-presets

分離の条件と合成のパラメーターのプリセット。種類ごとに 1 ファイル (`separation.json` / `mix.json`)。分離のプリセットは、方式の選び方 (おすすめ、モデルと結果の決め方、「除去・調整」の加工、または「エフェクト」) から詳細な設定までの条件一式を持つ (`method` と `params` を持たないものは画面に示さない)。
ファイルが無い間は初期状態 (合成は初期のプリセットだけ、分離は空) として扱い、最初に保存したときにファイルを作る。
ファイル名の種類は `separation` と `mix` に限る (それ以外は `INVALID_PRESET_KIND`)。

| 項目 | 型 | 必須 | 説明 | 関連 |
|---|---|---|---|---|
| version | `1` | ○ | 形式のバージョン | |
| presets[].id | string | ○ | プリセットの識別子 (初期のものは `builtin-*`) | |
| presets[].name | string | ○ | 名前 (初期のものは空文字で、表示名は `nameKey` から作る) | |
| presets[].nameKey | string | - | 初期のプリセットの表示名の翻訳キー (`voice.mix.builtin.*`) | `renderer/i18n/locales/*-voice.ts` |
| presets[].builtin | boolean | ○ | アプリが用意した初期のプリセットか。true のものは上書き・名前変更・削除できない (`PRESET_BUILTIN`) | |
| presets[].params.method.mode | `'recommended' \| 'model' \| 'other' \| 'effects' \| null` | - | (分離) 方式の選び方 (おすすめ / モデル / 除去・調整 / エフェクト) | `SeparationMethodChoice` |
| presets[].params.method.recommended | string | - | (分離) おすすめから選んだもの (`<目的>\|verified:<組み合わせの ID>` または `<目的>\|model:<ファイル名>`) | model-list.json の `ensembles[].id`・`models[].filename` |
| presets[].params.method.keys | string[] | - | (分離) モデルの一覧から選んだもの (`model:<ファイル名>`) | model-list.json の `models[].filename` |
| presets[].params.method.algorithm | string | - | (分離) 2 つ以上のモデルを選んだときの結果の決め方 (`avg_wave` など) | `ENSEMBLE_ALGORITHMS` |
| presets[].params.method.other | object | - | (分離) 「除去・調整」の加工 (残響・エコーの除去 `dereverb`: `{enabled, model}`、無音部分の雑音を消す `muteSilence`: `{enabled, thresholdDb, minSeconds}`、ノイズ除去 `noiseRemoval`: `{enabled, method ('simple' \| 'wavelet' \| 'model'), floorDb, reductionDb, waveletNoiseDb, waveletPercent, model}`、音量をそろえる `loudness`: `{enabled, targetLufs}`)。無い場合は初期値 | `SeparationOtherChoice` |

| presets[].params.params | object | - | (分離) 詳細な設定。全アーキテクチャのパラメーター (`mdx`・`vr`・`demucs`・`mdxc`) | `SeparationParams` |
| presets[].params.vocalGainDb | number | - | (合成) ボーカルの音量 (dB) | `MixParams` |
| presets[].params.accompanimentGainDb | number | - | (合成) 伴奏の音量 (dB) | 同上 |

## cache.json

キャッシュディレクトリのうち、アプリが読み書きするファイル (model-list.json・model-sources.json) の最終利用日時の記録。
起動時に、記録のあるファイルはこの日時で、記録の無いファイル (ライブラリが作るキャッシュ) は最終更新日時で、
保持期間 (settings.json の `storage.cacheRetentionDays`) を過ぎたものを消し、消したもの・無くなったものの記録を除く。
読めない場合は空として扱う。保存場所の移動では、移動元と移動先の記録を合わせ、両方にあるものは新しいほうの日時にする。

| 項目 | 型 | 必須 | 説明 | 関連 |
|---|---|---|---|---|
| version | `1` | ○ | 形式の版 | |
| entries.`<相対パス>` | number | - | ファイルの最終利用日時 (ミリ秒)。キーはキャッシュディレクトリからの相対パス (`/` 区切り) | model-list.json・model-sources.json |
